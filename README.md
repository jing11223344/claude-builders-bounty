# CHANGELOG Generator Skill

## Quick Start

1. `git clone <this-repo>`
2. `chmod +x generate_changelog.sh`
3. `./generate_changelog.sh`

## Features

- Automatic commit categorization (Added/Fixed/Changed/Removed/Other)
- Conventional commit prefix support
- Configurable since-tag
- Clean Markdown output
- No dependencies beyond git and bash
